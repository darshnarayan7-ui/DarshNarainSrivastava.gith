# Darsh Narayan — Photographer Portfolio

A story-led photography portfolio exploring urban life, heritage, wildlife, botanical detail, people, and light.

## View the portfolio

Open `index.html` for the visual portfolio. The portfolio includes 60 edited images, a story section, a cover letter, and a concise photography resume.

## Files

- `index.html` — portfolio landing page and gallery
- `cover-letter.html` / `cover-letter.pdf` — photographer-styled cover letter
- `resume.html` / `resume.pdf` — photography resume
- `assets/images/` — 60 web-ready edited images
- `assets/styles.css` — visual system and responsive layout

The copy intentionally describes the visible work without inventing client names, awards, or employment history.
